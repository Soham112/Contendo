Gullwing is an open-source command-line tool I wrote on weekends in 2024 to diff the outputs of two prompts side by side. It has about 1,100 stars on GitHub.

For the first two months it had 30 stars. I wrote the README last, as an afterthought. When I rewrote the README first, as if the tool already existed, with three copy-paste examples, stars and issues tripled in a month without a single code change.

I now write the docs page for every Sieve feature before the code.
