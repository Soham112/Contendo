Gullwing two-year retro

I started Gullwing on weekends in 2024 because I was tired of pasting two prompt outputs into a diff tool by hand. It now has about 1,100 stars and a handful of regular contributors.

What worked: rewriting the README first, as if the tool already existed. Stars and issues tripled in a month without a code change. What did not: I said yes to every feature request in year one, and the config file grew to forty options nobody understood.

For year three I am cutting the options to ten and writing the docs page for each one before touching the code, the same rule I now use for Sieve.
